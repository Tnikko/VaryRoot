# 三类 CVE 泛化机制：描述证据首轮归组

本表覆盖目录中的全部 300 条候选记录，每条仅分配一个主机制。归组依据为本地 NVD 描述的匹配片段及少数人工修正，具体片段见 `mechanism_assignments.csv`。**仅 4 条核查了上游补丁，其他机制是待验证假设，不是已证实的源码级根因或 VaryRoot 测试结论。**

分类时优先具体因果描述；仅有漏洞类别、产品和函数名的记录归入 `描述不足`。同一案例可能兼有多个机制，本表为统计而只取第一个可辨识的主机制。变量名变化只是表象；真正需要泛化的是来源契约、对象同一性、边界表达式和生命周期顺序。

## 资格问题

- 空指针目录：CVE-2026-100082 的主因是并发 UAF；CVE-2026-64229 是禁用 PCID 后的硬件指令 #GP。两者应从空指针机制分析中排除。CVE-2026-50126 同时涉及空指针和越界，需拆分路径。
- 越界目录：CVE-2026-106115、CVE-2026-106118 属于 ImageSharp（.NET/C#），不符合 C/C++ 范围。
- UAF 目录：16 条描述含异步、线程、中断、定时器等线索；`scope_note` 已逐条标记。是否存在单线程触发路径必须读补丁和调用链后判断。

## 可复用的判定关系

| 类别 | 判定关系 | 可变化的表象 |
| --- | --- | --- |
| 空指针 | 实际被访问对象 `o` 在可达路径 `p` 上须满足 `o != NULL`；检查其他别名或采用错误返回约定都不能替代它 | 变量名、来源 API、字段层数、helper、错误码表示、条件分支 |
| 越界 | 对同一缓冲区须证明 `0 ≤ offset` 且 `offset + width ≤ capacity`，计算须避免整数溢出并统一单位 | 文件格式、读写 API、索引/长度字段名、元素与字节单位、分配位置 |
| UAF | 同一分配对象的 `free` 若先于 `use`，两事件之间无重新建立有效生命周期，则访问无效 | 指针别名、释放 API、引用计数、容器、调用层级、清理路径 |
