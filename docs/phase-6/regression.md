# C5 · 逐位置回归、双版门禁与账本

一行对应组、查询版本、构建、TargetRef、契约与观察域版本。表内五项分别取自独立工件，各自保留出处。两版比较引用同一份位置清单与裁决。

| 证据标签 | 规约预测 | 实现默认 | 后端缺口 | 实际查询输出 |
| --- | --- | --- | --- | --- |
| 已揭示且当前有效的 positive／negative；pending 仅作观察 | 对应 S₀ 或 S* 在该位置的 report／quiet／uncovered 及推导链 | 仅对 uncovered 登记 no_alert，其余为空 | none 或已定位的能力／事实缺口及依赖范围 | hit／no_alert，或 unavailable 和运行／映射诊断。引用 C3、C4 原始记录 |

计分与门禁分别计算。对确定且可对齐、运行完成的位置，positive × hit/no_alert 分别计 TP/FN，negative × hit/no_alert 分别计 FP/TN。uncovered 的确定正例实际无告警时照计 FN；缺口存在但仍取得有效实测也照计，包括偶然正确的命中。无可计分结果记入阻断位置及其原因，保留总分母、可计分数和排除数。双版差值只在共同可计分位置上计算，并同时给出各版单独计数。pending 保留在旁表；过期／互相冲突的裁决先核对版本。禁止把编译失败、运行中断或歧义填成 no_alert。

## 路由与预算

| 检查 | 协调器动作 |
| --- | --- |
| 清单过期、缺行、重复或跨组，或版本与 B6 不相容 | 阻断发布，核对输入和依赖。若裁决／规约资格变化，退 B4 重验 B6。不得采信缓存中的旧通过标记 |
| 编译／执行未完成、位置不可唯一对齐 | 分别回 C2/C3 或 C4。实际输出不可用。基础设施重试使用原请求；确认问题无法恢复则按编译、运行或位置失败部分交付 |
| 明确预测依赖当前后端缺失的事实或表达能力 | backend_gap 单列。存在可核实的提取／实现修复时按依赖重建；已确认超出本批能力时部分交付。完整运行且能对齐的实测照计，正确输出也不能消除已知缺口 |
| 实测与对应明确预测或默认不符 | 先核对后端绑定、默认分派和匹配器；确认实现偏差后转 C2。保存失败父构建及逐位置差异 |
| Q₀ 实现一致但证据相反 | 该位置通过基线忠实度门禁，保留 FP/FN；不能用修复预算优化旧规约的已知语义错误 |
| Q* 与 S* 一致但 S* 与确定证据不符，或在 M 上只有 uncovered | C5 → B4。提交版本化反证包，含目标、证据与证明、B6 快照、解释器重放、C4 依据和实际输出。B4 核查后通过新 Decision 和 B6 重新交接；不直接修改谓词。正常情况下 B6 已拦截这类输入，C5 是针对数据变更或上游错误的独立复查 |
| M 上全部位置通过本版条件 | 发放仅对当前输入摘要有效的 lane_pass。Q₀ 须忠实于明确预测及默认。Q* 另须在每个确定位置作出正确的明确预测并获相应实测。两版再交 C6 成对验收 |

同一行可有多项诊断，独立保留。明确识别的 S*／证据矛盾即使与实现缺口并存也发给 B4；未核实输出不能用来断言“已忠实实现”。Q₀ 与 Q* 使用各自等额的初始预算。第一次构建成本单列，新修复意图在生成前按 lane 扣费，重试同一请求沿用围栏；勘误映射重放不涉及查询修改时不扣。产生修复需求且余额为零时保留原失败及 budget_exhausted 两项。恰好用尽预算但最新构建已通过，仍可进 C6。[预算与恢复协议](../phase-2/recovery.md)

## goto 的三种归因

先读独立裁决对故障路径和正常到达的证据，再读解释器登记的 Reaches 来源（前端事实或经核准的抽象假设、精度及作用域），最后读后端取用的关系。规约只声明 return 是必要条件，而故障路径已绕开目标时，report 缺少到达见证；Q₀ 若自行报出则查实现。如果旧模型确实显式登记且容许保守近似的可达关系，按该版本的完整 1B 推导能推出 report、实际也报、证据却为 negative，则保留基线 FP，并指出近似来源。若该关系未经允许或与当前事实快照矛盾，先退回核查事实／推导资格，不能事后为误报增设假设。解释器明确 quiet 但 QL 漏掉绕行边而报出，则为后端偏差。实测只给告警时，须取得上述推导和绑定依据才能作出归因。
