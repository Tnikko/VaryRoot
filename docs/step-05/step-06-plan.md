# 步骤 06　Agent B 与规约校准闭环实施计划（待审）

入口为当前生产种子版本、A6 接受记录、原始基线和存活解释，验证调用步骤 05 的独立角色。本步在已登记的受控访问工件上验收文件流与选择算法，独立评测在查询冻结后另行实施。

| 次序 | 编码交付 | 运行验收 |
| --- | --- | --- |
| 06a　提案与候选池 | 接入带父版本、争议条款、目标表达式及单一变化因素的局部提案。结构不变量由前端核对，语义不变量绑定独立契约。冻结共享池、去重键和候选解释。 | NPD、OOB 各跑一份；混杂变化、映射歧义、契约缺项不产生选择或扣费。登记未获支持的机制。 |
| 06b　预测和双组选例 | 在登记快照上用真实解释器生成三值预测。两组锁定同池、版本和等额预算。分歧组优先覆盖新的硬分歧对，其次覆盖域差异；稳定排序裁决并列。随机组按固定种子从同池抽样，只取得池成员与预算。 | 重排输入、并列、无硬分歧、K=0、K 超出池大小及更换预测矩阵。实测随机进程的可读目录与输出；同一组可重放、两组揭示水位独立。 |
| 06c　揭示与归因 | 提交 selection 后派发真实验证请求。按证据及骨架、预测忠实度、条款边界的顺序处理。待定保留、案例失败单记、基础设施失败沿用请求。勘误和退回 A2/A5 追加版本与来源。 | 用两组交叉选中同一案例验证独立计费和可见性。用生产 A4/A6 重验返工包，核对原始基线、剩余预算和 post_remodel 水位。 |
| 06d　B6 回查与交接 | 从组内已揭示账本构造全部确定目标；逐一核对 changed_judgments、preserved_judgments、规约冲突以及保留依据。生成 revise、keep 或 unresolved 工件。 | 修订与有据保留可提交 C 的输入；未决终止不创建 C 请求。两类种子都经过真实解释器和验证器。全量回归后复核 R05、R08，以及 R10 的 B→C 交接前置项。 |

交付选例与预测原始记录、逐位置证据和归因、B6 全量核对、状态事件链、容器隔离与重复运行日志，以及步骤 07 待审计划。
