# 目标访问的两类观测适配器

两类适配器共用目标身份、契约和到达路径。见证表示在保留程序语义的骨架中到达该操作并请求了相应访问，不要求通过执行非法访问来制造崩溃。探针改变求值次数、控制条件、操作数身份或正常功能时，骨架须退回 A2/A3。

## NPD：记录实际操作数

绑定目标读取／写入位置、故障来源、到达时的值版本、实际对象及代次。早退或跳转记录 fault → blocked 的边和正常输入的 used 见证。状态修正记录原空值、重绑定事件、新值和它所指对象的核准保证；到达时只看到一个非空数值不足以签发正常访问见证。无法证明对象有效时，标记缺少契约；已证实是另一类对象生命周期问题时单列诊断，避免误归 NPD。

| 输入轨迹 | 观察 | 声明域与预期裁决 |
| --- | --- | --- |
| 判空记录后继续 | 空输入到达指定目标，操作数仍为空 | 有效违规见证 → positive |
| 判空后退出 | 空输入 blocked；有效输入在相同目标 used | 两种输入穷尽、正常功能见证有效 → negative |
| 空值经修正后继续 | 重绑定至有效对象；正常与修正路径均在目标 used | 修正的成功保证独立核准且覆盖所有相关模式 → negative |
| 修正依赖两种模式 | 一种故障模式 blocked，另一种未观测，正常路径 used | partial_sample，无违规见证 → pending |

## OOB：在指针形成前捕获访问请求

1. 选择能取得对象身份、偏移和宽度的**最早安全切点**。如果准备实参时就可能形成越界指针，探针须位于该运算之前。以对象代次和逻辑偏移表示请求；避免为取证先构造候选地址或对不相关指针作差。含副作用的表达式只求值一次并保留原有顺序约束。无法建立等价的前置观测时返回适配诊断。
2. 捕获源操作数、类型、单位、整数提升、转换与各步有效结果。对已定义的截断／无符号模运算记录转换前值、操作后值及生效位宽。数学上的未截断值可作为派生诊断，单独标为 derived。已发生未定义行为的源表达式没有可采信的后值；若故障先于目标，返回 case_exec_failure，不能假定回绕。构建模式或求值顺序不明且影响结论时，要求核准或收窄范围。
3. 按实际对象及访问语义选取独立核准的有效范围，注明是数组、子对象还是其他契约边界。容量属于该对象，以字节为单位。偏移从对象起点计算；若起点是内部位置，先用数学整数合成基偏移与增量。若请求来自元素数，按已核准的元素大小换算，并记录原表达式实际发生的类型转换。
4. 对正宽度访问，在独立观察器用数学整数计算 end = offset + width；条件为 0 ≤ offset、width > 0、end ≤ capacity。输出起止值、负偏移标志、宽度类别和结果。违规请求在真正读写之前终止本次目标访问。安全请求要保留正常路径见证；对需要执行后续语义的案例，核对替身操作的返回值与副作用。

源程序的整数语义与观察器的精确区间运算分别保存。例如发生整数提升后的加法本身可能没有回绕，而随后赋值到窄无符号类型才截断。适配器须记录实际生效的那一步。C 与 C++ 各按绑定的语言版本和 ABI 核准；C++ 的整数和指针规则可参见[基本整数类型](https://eel.is/c++draft/basic.fundamental)与[指针加法](https://eel.is/c++draft/expr.add)。

| 目标对象契约与有效请求 | 数学结果 | 观察如何使用 |
| --- | --- | --- |
| 容量 8、偏移 6、宽度 2 字节 | [6,8)，合法 | used；若为已完整核准的单路径单输入域，可得 negative |
| 同一对象、偏移 6、宽度 3 | [6,9)，尾部越界 | 前置违规见证 → positive |
| 同一对象、从对象起点偏移 −1、宽度 1 | [−1,0)，起点在对象外 | 记录负偏移及来源，前置见证 → positive |
| 容量 255，逻辑偏移 254、宽度 3 | end=257。若仅用 8 位保存 end 会得到 1 | 探针保留 257；即使原检查使用了窄值 1，也按实际访问请求判 violation |
| 不同案例：原始偏移 257 经已定义的 8 位无符号转换变为 1，容量 8、宽度 1 | 实际请求 [1,2)，合法 | 保存 257→1，按实际请求得到 used。截断记录本身不足以证明访问越界 |
| 容量 8、偏移 8、宽度 0 | 无正宽度读取 | 先查接口。若契约允许该条件下空操作，记录 no_access；不能用其充当正常读取见证。零宽度前置条件不明则留缺，违反其他接口前提单列诊断 |

若源有符号宽度为负，先区分它是在访问前被契约拒绝，还是经定义明确的转换成为实际无符号宽度。适配器不能擅自将其修正为零。丢失的原始值保留 unknown，有效请求、目标身份或路径受到影响时阻断确定判断。
