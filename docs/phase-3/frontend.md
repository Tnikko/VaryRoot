# 阶段 3 · 源码前端与事实提取契约（A1、A3）

前端接收协调器授权的修复前后源码快照、补丁、编译配置及目标访问提示。A1 为每个版本分别定位访问；A3 核查骨架与原程序的对应关系。交付给 A2 的是位置索引、事实快照、依赖及缺项。是否接受种子由[种子包门禁](seed.md)决定。

## 解析输入与身份

解析配置绑定翻译单元、编译器和前端适配器版本、语言模式、目标平台、宏定义及参与解析的头文件摘要。缺失的配置或依赖若能改变目标语义，应返回 parse_context_missing。预处理配置不同的两个版本不能共用 AST 定位缓存。解析诊断影响到目标的类型、展开或作用域时，记录缺口；错误恢复生成的 AST 节点不直接作为已核准事实。

| 字段组 | 交付要求 |
| --- | --- |
| 源码身份 | 继承阶段 1 的 scope_kind、snapshot_ref、variant_id、文件相对路径及摘要、目标表达式的 UTF-8 半开字节跨度。行列供显示；原始编码与解析文本不一致时附偏移映射。 |
| AST 与操作 | ast_kind、从所属声明根到节点的结构路径、access_ordinal、operation（读、写或读改写）。序号按已版本化的访问节点遍历顺序生成，不能解释为运行时求值次序。一个表达式承担多个操作角色时再按角色区分。 |
| 作用域与上下文 | enclosing_decl 包含限定名、签名及源定义锚点；context_policy 明确按定义还是按调用点计数。调用敏感模式附有序 callsite_refs，模板实例另记特化身份。定义级样本仅计一个定义位置。 |
| 来源 | origin_trace 记录普通源码、宏展开链、内联调用链等来源。对宏保留拼写位置、展开调用位置、必要的形参与替换体使用点；对内联保留函数定义与调用位置。上下文不可重建时显式记录 unknown。 |
| 映射质量 | mapping_ref、mapping_status 采用[阶段 1 词表](../phase-1/artifacts.md)：origin、exact_1to1、split_expression、ambiguous、unmapped。macro_expanded 属于来源属性。宏来源也可能有精确映射，普通源码同样可能歧义。 |

在固定解析配置中，用快照、变体、翻译单元、声明、结构路径、操作角色与约定上下文生成 TargetRef 身份，另存跨度、序号和来源用于复核。不持久化 AST 进程地址。跨版本只使用经过核准的映射；结构路径或序号恰好相同不能证明语义相同。

## 前端事实输出

每条 Fact 携带 ID／版本、类型化主客体、操作或关系、路径条件、程序点、source_kind、source_ref、approval_status 和直接依赖。指针重赋值时，旧值和新值在不同程序点有独立绑定；访问路径和对象状态必须属于同一执行上下文。提取与核准分别留痕。

| 来源类别 | 示例及依据 | 缺项如何处理 |
| --- | --- | --- |
| source_extracted | 某调用参数经何种类型转换到达访问；哪个分支通向清理出口。附 AST／控制流位置、构建配置及对象绑定 | 前端不能判定两个别名时返回 unknown_identity，指出依赖它的 Propagation 或 Guard 条款 |
| interface_guarantee | 成功分支保证返回对象有效；容量接口以字节描述指定对象。引用版本化实现或接口契约、适用模式 | 只核准接口中实际有依据的条件。长度值已知但单位未知时返回 missing_unit，定位到单位转换及区间包含 |
| skeleton_assumption | 模型提出替代调用总成功、两个长度总相等。附提案、替换位置及父快照，初始为 pending | 通过来源核对才可核准；发现冲突标 rejected。不能以桩执行成功为自身提供依据 |

缺项诊断包含 target_ref、clause_ref、required_fact、已查证的来源、受阻推导和责任方。前端向解释器报告缺项，最终是否 uncovered 仍由全部适用条款决定。目标或契约必需绑定不完整时，A6 也不能凭其他无关条款放行种子。

## 同行访问的判别

在 C++ 表达式 `buf[0] + buf[1]` 中，两个读取分别绑定各自 ArraySubscriptExpr。在 `PAIR(buf[0])` 将同一实参使用两次时，两处访问可以共享拼写与展开位置；再按所属作用域内 AST 路径及宏使用点区分。对 `read0(buf) + read0(buf)`，源码有两个调用点，函数体只有一个读取定义；按调用点分析时两者与同一函数体组成不同上下文。具体编译产物中的内联实例需相应后端映射证据。只能看到粗粒度行号时，保留本地 TargetRef，将跨工具映射标为 ambiguous，阻断跨位置及跨版本计分。
