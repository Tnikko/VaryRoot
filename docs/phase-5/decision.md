# B4–B6 · 归因状态机与修订契约

本组收到阶段 4 已提交的揭示后，B4 才对照证据与登记预测。模型可提出归因和条款变更；协调器核对工件资格、状态和门禁后提交。若当轮有多个问题，先按位置分别归因；需要回退或仍影响定稿的问题阻断全组定稿，已经有效的证据保留。

| 优先级 | 条件 | 责任与转换 |
| --- | --- | --- |
| 1 · 检查案例与证据 | 所用骨架或契约失真 | 记录 Decision 及受影响依赖，B4 → A2，当前种子工作包回 seed_pending。重新核对目标及域后再判断旧观察能否复用 |
| 1 · 检查案例与证据 | 未揭示、围栏或版本无效、映射不唯一、裁决待定、运行失败 | 不淘汰解释。未揭示时等待；诊断按阶段 4 路由。能够补证时 seek_evidence；无预算／无可裁决证据且关键分歧仍在时 unresolved |
| 2 · 检查预测忠实度 | 登记使用了错误事实、错误方向或解释器推导与登记条款不符 | correct_reading；保留原预测和选择，追加 errata 与 supersedes、当前水位。错误由解释器导致时暂停使用该版本。纠正后重新进入 B4，不把勘误当原始预测命中 |
| 3 · 判断条款错误／遗漏 | 确定裁决与一个明确预测相反 | 排除该解释在声明范围内的此版本，记录明确反驳的见证。若所有解释都被可信证据反驳，回 A5；否则定位错误条款，选择有依据的工作规约送 B5 |
| 3 · 判断条款错误／遗漏 | 裁决确定，但该解释预测 uncovered | 登记覆盖空白及缺失事实。若已有足够事实和对照支持新条款，可提议扩域；若因事实未核准而缺项，先补事实。uncovered 不构成证据反驳 |
| 4 · 保留或未决 | S₀ 对本组全部确定位置给出正确明确判断，且有与当前争议直接相关的确证，剩余实质分歧已裁决或在声明域内有明确等价依据 | 提议 keep，列出支持位置、适用范围及等价依据。只有无语义改动并通过 B6 才交付 S* = S₀ |
| 4 · 保留或未决 | 尚有能改变结论的相容解释、关键待定位置或未满足的补证条件，而本轮不能继续 | 提交 unresolved：列出相容解释、待定位置、预算、剩余分歧及停止原因，交付部分结果。预算耗尽只是停止条件；没有发现反例不能代替 keep 的证据 |

当前只有一个假设、或有限候选池中预测相同，均不自动证明其正确或逻辑等价。可以在明确收窄且有依据的合同域中定稿，须另记适用域变化及其影响，避免临时删去困难位置。

## B5 提案与 B6 提交门禁

1. B5 引用触发决定和有资格的证据，提出候选 S*。保留只写 Decision；实质修订另有 Revision。其中记录条款差异、改变与保持的判断、新增事实需求。若仍有会改变定稿结论的未决项，停留在 B；补证、重建和失败均不生成可交 C 的定稿包。
2. B6 从组内已揭示台账**独立重建**确定位置清单 M（含种子和本组已取得的确定开发位置）。位置键由 TargetRef、契约、观察域和对应 Verdict 版本唯一化。pending、技术失败、过期裁决另列原因和计数，不能靠删除记录缩小分母。
3. 对 revise 校验 `changed_judgments` 和 `preserved_judgments`。两表无重复、互斥且并集等于 M；每条四元组唯一引用 M 中的裁决。旧预测须与父规约对应快照一致，新预测须等于新规约在同一组位置独立重放的结果。若父预测已勘误，明确所用版本，同时保留原登记，不能改写选择历史。changed 要求旧新值不同，preserved 要求相同。
4. 对 keep 校验无条款语义差异、不产生 Revision，并逐项重放 M。对两条路径均要求确定正例得到明确 report、确定反例得到明确 quiet。由查询默认产生的“安静”不足以满足这一版工作规约在确定开发位置的解释要求。条款冲突、回查不符或断言清单无效时退 B4，保留失败候选与诊断。
5. 协调器在当前版本和输入水位仍有效时提交 spec_ready。对 C 交付首次登记的基线引用、本组定稿、Decision、可选 Revision、确定位置清单、证据与预测版本、待定和失败清单。基线在明确分歧上的原错误作为比较材料保留。

## 全部解释被反驳

在前两层归因通过后，要求**每个**存活解释至少有一条在其适用域内与之明确相反的确定证据，才能宣布全部被反驳；这些证据可以来自不同位置。生成 remodel，引用解释到反驳证据的逐项映射。按[阶段 3 返工协议](../phase-3/seed.md)回 A5，固定首次登记的 S₀/Q₀ 引用，仅升版工作规约与竞争集。有效骨架与本组证据继续使用，组内可见快照、剩余额度及父决定随分支继承。新预测标 post_remodel；按该目标首次揭示顺序审计。完成 A6 重新核准后才可回 B。
