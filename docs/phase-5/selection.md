# B2–B3 · 预测登记与选择器规范

## 可比较的输入与隔离

在配对比较开始前，协调器冻结同一 seed、S₀、解释集合、候选池、验证器配置、可用求证契约和预算上限 K。按位置建立中性 ID，该 ID 及其排序不得由标签、预测、机制分数或模型推荐顺序产生。每个位置绑定案例版本、契约和观察域；重复的逻辑目标去重并保留其配对关系。已公开的种子标签另列。池记录入选与被拒提案的边界，生成 pool_digest。抽样前用相同解释器为全部存活解释和候选目标登记三值预测、推导链及可见证据水位。invalid_ir 或 spec_conflict 先修复；未覆盖是合法预测。

首版比较采用预登记的单批选择。各组后续取得私有标签后可以在各自分支归因与修订；不得用一组得到的结果修改另一组的候选池或解释。若研究中另开多轮，登记每轮父快照、公共材料和组内状态。解释已随私有证据分化的轮次不能声称有相同的活跃解释集。重启重放既有选择，修改池、策略或矩阵须另立版本。

| 选择器 | 角色可读输入 | 输出及审计 |
| --- | --- | --- |
| random | 中性目标 ID 的规范排序清单、预算、rng_seed 和抽样实现版本。协调器持有登记矩阵；不向随机执行器传其内容、得分、预测衍生排序或提案理由 | 无放回抽样；记录 RNG 算法／运行时版本、种子、排序规则、pool_digest、逐次入选 ID。复核时按锁定实现重放，已提交重试直接取回旧记录 |
| divergence | 同一候选位置清单，加已锁定的三值矩阵和解释版本、预登记等价改写标记 | 记录每步尚未覆盖的解释对、分数、同分裁决、回退原因与最终 ID |

同一轮先登记矩阵再允许任一组抽样。协调器在选择事务中关联 prediction_batch，而不把它交给随机选择器。random 固定预算取 min(K, 可选数)，重复实验的 rng_seed 提前登记；divergence 也不得超过同样上限。若提前停止，报告实际使用预算和停止原因。

首版随机重放约定使用 CPython 的独立 random.Random 实例，以预登记的非负整数为种子，对按 ASCII 字节升序排列、无重复的中性目标 ID 列表调用 sample，样本量为 min(K, 列表长度)。输出保留抽取顺序，登记 CPython 完整版本。池摘要及预测登记引用由协调器在抽样器返回后附入选择记录。池形成阶段的提案分布仍可能带有偏好，两个策略的比较以同一已冻结池为条件。

## 确定性分歧选择

记一个位置 x 上的硬分歧集合 H(x) 为报告与不报告预测构成的无序解释对，覆盖域差异集合 U(x) 为一方明确、另一方未覆盖的无序解释对。两个未覆盖不产生信号。一次批次开始，两类已覆盖集合分别为空。

1. 对所有未选位置计算两项边际增益：h 为 H(x) 减已覆盖硬分歧集合后的大小，u 为 U(x) 减已覆盖域差异集合后的大小。
2. 若有正增益，按 h 降序、u 降序、中性 ID 升序选一个，分别并入两个覆盖集合。先前从域差异看到的解释对仍可在另一个位置产生首次硬分歧。
3. 两项新增增益均为零时，从**入池前已登记且有等价依据**的未选改写中，按中性 ID 升序选一个检查共同盲点；没有此类位置则停止并登记 exhausted_signal。区分“全池预测一致”“只有域差异”“已有信号全部覆盖”。新提案要在新池中登记，不能临时加入本批。
4. 预算用完或池为空即结束选择。K=0 时无请求、无扣费；仅一个活跃解释时直接适用共同盲点或停止策略。增益表示预测能否分开；只有合格且已揭示的确定裁决才能反驳明确解释。

没有存活解释时应先检查反驳见证并按 B4 转 A5，不能当作单解释或零增益批次。准入后的同一位置即使同时属于多对对照，在本轮仅可选择一次。

selection 事务和 B3 的接收规则继承[阶段 2](../phase-2/recovery.md)与[阶段 4](../phase-4/verdict.md)。确定裁决、待定、案例失败、基础设施重试分类入账。本组消费证据前须有独立的 Reveal；不能从另一组已经运行过同一个案例推知结果。
