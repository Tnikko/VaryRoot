# OOB 查询开放扫描：锚点剥离设计（待审）

**状态。** Step 4f 的 OOB 查询只是可行性探针，校准结论为 `unresolved`；本设计不签冻结包，也不启动未见仓库评测。

**查询层。** 从 `oob_interval.qll` 的 `targetCopy` 删除 `targetFunctionName()`、`targetLine()` 和目标局部变量名约束。共享查询按声明式契约识别候选：拷贝 API 及源/宽度参数位置、常量字节宽度、源指针与逻辑载荷基址的关系、`end = base + logical_length`、正向指针推进，以及同对象同单位的总长/剩余长度 Guard。保留函数内基本块级可达，限制连接范围；两版查询共用 `site`、绑定和缺口谓词，只替换 Guard 判定。Ettercap 的字段路径与常量放入契约参数，不进入共享 QL。

**C4 对齐。** 查询对全库候选输出仓库相对路径、调用表达式的起止坐标、`site/alert/gap`、源调用与槽身份、宽度和匹配重数。C4 用已登记目标的文件快照及精确表达式字节跨度作一对一对齐；同文件邻近告警不能替代目标。开放扫描另按 `(source call, slot)` 聚簇，保留原始逐位置告警数与聚簇数。

**判定边界。** 仅当基址、逻辑末端、推进量、宽度、Guard 控制关系均可证明时输出可评分的差分候选。别名/重赋值、宏封装拷贝、非常量或单位不明宽度、复杂布尔 Guard、跨函数容量、路径可满足性未证明及多重绑定均标 `backend_gap`，不能当作 `quiet`；建库或查询超预算单列 `execution_limit`。首轮须用 Ettercap 父/修复版与无关解析函数核对新旧目标逐位置一致，并加非目标函数控制样本。正式未见评测仍须等待新校准得到唯一解释、双版回归及冻结。

**未见仓库预选。** 候选为 `libarchive`、`c-ares`、`tcpdump`，仅作待筛清单，不预称合格样本。预登记前只核对上游版本、许可证、C 构建可重现性、与开发材料的源码/补丁重叠；锁定仓库提交、排除理由和资源预算后才读目标源码、建库和运行冻结查询。不因首批告警结果更换仓库或调整查询；分母不足如实记录。
