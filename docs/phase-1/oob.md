# OOB 贯穿实例 · 起点、访问宽度与目标对象容量

本例是设计向量。K2 将目标缓冲区 B 的有效容量核准为 8 字节；该值取自独立对象契约。程序自身比较的长度另有事实引用，二者只有经对象绑定核对后才可关联。访问偏移固定为 6 字节，一个变体读取 2 字节，另一个读取 3 字节。给定每个变体的域只含其固定输入和一条可行路径，读取意图可达。数值在该域内精确表示。

## 位置与独立证据

| TargetRef 与域 | 目标区间及观测 | Verdict |
| --- | --- | --- |
| B.w2@1，D2：容量 8、偏移 6、宽度 2 | 观测目标为 B，请求 [6,8)，在 [0,8) 内。正常访问可达且已穷尽 D2 | V.w2@1，negative，仅在 D2 内成立 |
| B.w3@1，D3：容量 8、偏移 6、宽度 3 | 观测目标为 B，请求 [6,9)，超出末端。该可行请求是一条违规见证 | V.w3@1，positive |

两个 TargetRef 的 scope_kind 均为 counterfactual_case，variant_id 分别为 w2、w3，各自追到同一父骨架访问。若骨架将“计算偏移”和“请求读取”拆成两个表达式，记录 split_expression 并按请求读取的角色预登记子位置。若两处读取角色仍无法区分，C4 返回映射歧义，本地观测仍可保留。

## 三种条款／事实组合

1. **旧条款明确判断错误。** S₀ 将同一对象上的起点合法声明为任意正宽度读取的充分条件，两例都推出 quiet。S* 在目标对象、单位和范围已绑定的域内，将完整访问区间包含声明为充要保护。w2 得到 quiet。对 w3，来源为可能超出容量的访问请求，偏移和宽度传播到同一操作数，目标要求整个区间有效；同一可行路径上实际到达，且必要的区间包含条件被证伪。因此推出 report。D.b@1 记录 revise，并定位到 Guard 条款及其宽度绑定。
2. **旧条款适用域窄。** 若 S₀ 仅对宽度等于 1 的访问声明充分保护，则 w2、w3 均在条款域外。没有其他报告或保护条款时，两项预测均为 uncovered。Q₀ 的预登记默认都为无告警，w3 按独立证据计为漏报；将适用域扩展为多字节须记录为补充覆盖。
3. **程序事实缺少单位。** 保持 S* 合法，从解释器的事实快照中撤去“容量表达式按字节计”，保留验证器独立持有的 K2。类型仍合法，但单位转换与区间包含均得到 U，两个目标均返回 uncovered 和具体缺项；V.w2@1、V.w3@1 可继续使用。若撤掉的是 K2 自身的核准，则须检查裁决的证据依赖。若写下的是类型定义要求单位、却没有单位的 IR 常量，结果为 invalid_ir，在预测登记前停止。

## 修订断言与回归

以下摘录对应第一种组合。B6 按含 w2、w3 的清单回查全部确定位置。C5 用相同的 TargetRef 对齐实际输出，同时读取独立裁决，不能从下列期望值反推证据标签。

```json
{
  "trigger_decision_id": "D.b@1",
  "changed_judgments": [
    ["B.w3@1", "quiet", "report", "V.w3@1"]
  ],
  "preserved_judgments": [
    ["B.w2@1", "quiet", "quiet", "V.w2@1"]
  ],
  "new_fact_requirements": ["实际请求宽度", "偏移、容量与宽度的单位关系", "目标对象与容量来源的绑定"]
}
```

**两项拒收条件。** 如果将“宽度 3 来自故障输入”和“目标可达”分别取自互斥分支，路径不相容，无法推出 report。若解释器已得到明确预测，但后端数据库缺少实际宽度，应返回 C 的事实提取缺口，保留原 Prediction 与 Verdict。该回归不能以“未覆盖默认无告警”通过。
