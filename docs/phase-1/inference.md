# 1B · 解释器推导与错误语义表

解释器输入为规约版本、目标 t、契约 Dₖ、观察域 D 和登记时的事实快照。以下公式定义规约预测；独立验证器根据执行或覆盖证据给出裁决。弱规约能够推出明确但错误的预测，这正是校准的对象。

## 逻辑与原子关系

原子命题取 T、F、U。F 表示有依据的否定，U 表示缺失或不可确定。合取中有 F 即 F，全 T 才 T，其余 U；析取中有 T 即 T，全 F 才 F，其余 U。否定保持 U。存在量词需一条见证才能取 T；全称量词需覆盖依据才能取 T。无法证明某个事实不会产生该事实的否定。推导树保留目标、路径或路径类、对象版本及所用事实。

| 原子关系 | 成立／否定的依据 | 返回 U 的典型原因 |
| --- | --- | --- |
| 对象身份 | 同一观察时刻、同一对象实例的绑定／可证不同的绑定 | 别名或对象代次未决 |
| 空状态 | 指定位置该值为空／非空的路径事实 | 检查后值被重写，缺少新状态 |
| 路径阻断 | 所述故障路径在目标前退出或绕开目标／有可行的继续路径 | 分支可行性或调用返回契约未知 |
| 单位转换 | 有带类型的数值、单位、换算因子和转换语义，由此计算或证伪所述等式 | 已知条款类型，但事实缺少元素大小或容量单位 |
| 区间包含 | 对同一对象以统一单位比较偏移、访问宽度和有效范围 | 容量、对象身份、整数转换或回绕语义未确定 |

## 位置级闭合规则

用 Ω 表示 D 中属于该缺陷范围、与目标对象及这次操作相关的故障路径或已核准的路径类。它包含可能在保护处分流的路径。用 Aᵢ 表示条款适用域、Gᵢ 表示所声明的保护形式；方向 sufficient 代表 Gᵢ ⇒ P，necessary 代表 P ⇒ Gᵢ，iff 同时提供两条规则。P 始终限定到同一对象、状态、操作和路径范围。全局充分保护也可以由一条已登记的、覆盖整个 Ω 的条件证明。

**quiet 的推导。** Sink 匹配目标，目标及保护作用域已绑定，且有完整的保护推导：

`Quiet(t) ⇐ Sink(t) ∧ Coverage(Ω) ∧ ∀π∈Ω: ∃i [Sufficient(i) ∧ Aᵢ(t,π) ∧ Gᵢ(t,π)]`。

每条相关路径必须落在某个适用的充分保护条件下；不同路径可以由不同条款覆盖。单一路径上出现检查不足以推出位置受保护。空的路径清单不作为全称证明。若用不可达性证明排除所有故障路径，须显式登记该证明和对应的充分保护条款。充分条件可以证明故障路径被阻断，也可以证明到达时对象状态已经合法。旧规约若误将一次语法检查声明为充分条件，解释器会忠实使用该假设，并在推导中标明条款。

**report 的推导。** 下式所有条件在同一对象、同一可行路径及相容的状态时刻上连接：

`Report(t) ⇐ Sink(t) ∧ ∃π∈Ω: Feasible(π) ∧ Reaches(π,t) ∧ Source(π) ∧ Propagation(π,t) ∧ Failure(t,π)`。

Source 提供故障来源；Propagation 连接其携带值或对象到目标操作数。状态是否已被修正由 Guard 条款判断。Failure 仅接受以下两种有依据的导出：

1. 存在适用的必要条件，即 `Necessary(i) ∧ Aᵢ(t,π) ∧ ¬Gᵢ(t,π)`，其中否定必须有依据。
2. 规约显式声明某个非空保护集合 J 在当前范围完备，即 `P ⇒ ∨ⱼ∈J(Aⱼ ∧ Gⱼ)`，并且在**同一条**可行路径上，对每个成员都能证明 `¬(Aⱼ ∧ Gⱼ)`。缺少匹配记录或尚未提取条件时不能使用此规则。

必要条件被证伪但 Source 或 Propagation 缺失时，应报推导未闭合。若该位置另有完整 quiet 推导，仍可输出 quiet；双方向都无完整推导才输出 uncovered。把互斥分支上的来源、传播和保护失败拼接到一起不能形成见证。

| 情形 | 返回值 | 下游处置 |
| --- | --- | --- |
| 工件缺必填类型、悬空引用或操作数类型非法 | invalid_ir | 退回构造，禁止登记预测 |
| report 已推出，quiet 未推出 | report | 登记应报及见证链 |
| quiet 已推出，report 未推出 | quiet | 登记不应报及覆盖依据 |
| 两方均未推出 | uncovered | 区分域外、无适用条款、缺失事实、缺少覆盖等原因。查询默认无告警，确定正例仍计漏报 |
| 两方均已推出 | spec_conflict | 保留两棵证明树，阻断该版本选例与编译 |
| IR 已有明确结论，但查询后端缺必要事实或位置映射 | 后端／映射诊断 | 由 C 处理；保留原预测，不回写成 uncovered |

解释器预测仅依赖已登记的条款和前端事实。下游观测用于裁决或形成带新版本的勘误，不能倒填原预测的输入快照。
