# 步骤 07 编码实施计划（待审）

**目标**　在相同代码快照和同一 CodeQL 数据库上，将步骤 06 的两版规约逐位置编译、回归、成对冻结，并在空工作区重放。首轮使用已经登记的 C/C++ 合成访问与宏定位夹具。未见仓库评测另行启动。

| 顺序 | 实现与输入 | 独立验收点 |
| --- | --- | --- |
| 07a　C1 接收与能力登记 | 消费本轮真实 manifest 和 records，校验内容摘要、Decision、版本链及目标清单。仅接收 revise 与 keep。按条款规范化语义、对象绑定、适用域、方向及版本建立共享谓词索引。登记 CodeQL CLI、C/C++ 提取器、查询库、构建命令、数据库标识与适配器能力。预登记未覆盖的默认输出及两个等额独立修复账户。 | keep 显式空修订引用并共用同一规约及谓词，revise 可逐条追到 Revision，unresolved 在创建 C 请求前停止。缺少能力或数据库事实各有诊断。冻结前可离线核对工具和数据库摘要。 |
| 07b　C2–C4 编译、执行、对齐 | 先在一次真实的小型离线构建中生成数据库，再对同一数据库运行双版。分别保留完整运行状态、原始查询结果和规范化位置。按版本、文件、半开字节跨度、访问角色及必要的宏和调用上下文对齐。 | 回放同行双访问、多字节跨度及重复宏展开。后端粒度不足时阻断冲突集合全部目标。完整运行的空结果保留为空；编译中断或无法对齐记 unavailable。验收 R06 后端分项。 |
| 07c　C5 差分回归与预算 | 每个位置并列输出证据、规约预测、实现默认、backend_gap、实际输出，另记命中判定和可计分资格。双版共用未变条款，分别以幂等请求记修复支出。 | Q₀ 对齐旧条款，保留旧条款造成的错判。Q* 与 S* 一致而与确定证据冲突时退回 B4。未覆盖的确定正例在完整运行、唯一对齐且无告警时计 FN。后端缺口在可测位置按实测输出计分并阻断冻结。耗尽预算输出部分结果。核验 R09。 |
| 07d　C6 成对冻结与重放 | 同时核验双版门禁后签发一个冻结编号。清单绑定规约、查询、共享库、开发清单、位置匹配规则、原始结果、工具和数据库摘要、镜像、预算及门禁记录。 | 重放修订、保留、未决和后端缺口四条端到端路径。覆盖首次签发、重复签发、事务前后进程终止、旧水位、单版失败和归档缺件。空白工作区通过摘要核验后恢复同一数据库并逐位置重放。按实测结果更新 R10、R11。 |

**提交复核**　交付双版真实编译及执行日志、共享谓词映射、原始告警及表达式对齐表、C5 归因与预算账本、成对冻结或部分交付记录，以及空白目录重放日志。涉及工具使用或镜像分发限制时，登记已验证的版本与取得方式。步骤 07 待本计划批准后开工。
