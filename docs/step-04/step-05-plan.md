# 步骤 05　独立验证器实施计划（待审）

本步接收步骤 04 的版本化待验证种子。首版覆盖预登记的、可在目标访问之前安全观测的 NPD 和 OOB 合成夹具。完成条件为协调器能凭当前版本的独立观测、覆盖证明和解释器回放作出接受、留待验证或退回决定。

| 实施顺序 | 编码交付 | 独立验收点 |
| --- | --- | --- |
| 05a　请求与视图 | 用步骤 03 的围栏、租约、暂存和规范回执调度真实 verifier。清单绑定前后快照、目标、对象契约、驱动和观察域版本。只授予执行所需输入，分别给 A6 提供候选和裁决。 | 枚举 verifier 容器实际可读文件，候选解释、Guard、预测、告警均不可见。有效回执可取回；旧尝试或重复回执无法二次推进。 |
| 05b　安全观测 | 对受控访问记录实际求值一次后的对象、状态和访问意图。分别保存原类型、已定义转换、单位、偏移与宽度，用数学整数检查区间。记录退出或重绑定后的有效对象身份。 | 以计数器及事件顺序比较插桩前后的定义良好行为。覆盖负偏移、零宽度、贴边、越尾、窄化和未定义源运算；验证探针在无效访问或无效指针构造之前记录并中止该访问。 |
| 05c　标签与覆盖 | 用独立契约裁决。正例须有指定位置的违规见证；反例须有正常安全访问见证及声明域穷尽证明，或可检查的等价类证明。观察缺失单列。 | 覆盖多故障模式漏测、域截断、超时、死代码、目标歧义、错误对象容量和空操作。正常结束但待定消耗一次逻辑预算；案例失败单列；基础设施失败沿同一请求重派。 |
| 05d　A4/A6 接通 | A4 核查映射、见证、契约与观察域版本。A6 在相同快照上回放每个候选，按结果过滤或退回 A5。在 SQLite 同一事务核验预期种子版本再推进。 | 正向走通真实 A → verifier → A6；分别测试部分候选不相容、初始规约不相容、全部候选不相容、证据不合格、迟到回执、证据到达时种子已升版。复跑 04 的待审核反例，保持阻断。 |

阶段交付包括可重放的观测与裁决、版本事件链、实际隔离/故障测试命令、全量回归日志，以及 R07、R08 分项更新。R08 的 B 侧闭环留至步骤 06。较早文件桩中的裁决保留测试身份。
