# 输入清单、揭示水位与失效传播

## 授权单位

协调器按 run、seed、group、repeat、role、phase、request/attempt 和授权时刻生成 input_manifest.json。每项包含工件 ID 和版本、角色视图内的相对路径、字节长度、SHA-256、schema 及依赖版本。清单本身有摘要，随尝试和回执保存。构造查询须同时满足已发布、当前阶段可读、组内已揭示或预先登记为公共输入。批次预测还要引用当时选用的事实快照。

| 角色或组件 | 可见输入 | 写入／限制 |
| --- | --- | --- |
| A／前端 | 分配给本运行的开发种子、来源与契约、回退决定明确授权的材料 | 提案进入自己的 staging；重新建模若已看过证据，子分支继承其可见历史 |
| B 候选与解释器 | 公共种子、公共候选材料、本组已提交的事实和已揭示证据 | 不提供其他组选择、待揭示标签、回执、全局目录或 QA 汇总 |
| 随机／分歧选择器 | 共同池、各自预算和策略。仅分歧策略输入逐例预测作排序，随机策略使用预登记随机种子 | 登记选择不授予标签读取权 |
| 独立验证器 | 被选中的案例、目标身份、独立契约、声明域、必要工具 | 仅返回观察与裁决。预测、查询结果和分歧理由不进入清单 |
| C／回归器 | 本组规约、查询数据库、进入该角色所需的已揭示开发材料。回归器读取独立证据 | Q₀ 的修复以初始预测及默认行为为准；按版本给出修复诊断，另一组的补丁不可见 |
| 评测者 | 冻结包与预留材料 | 预留材料不进入开发角色视图；后续采纳的反馈只能进入新版本 |

角色只在只读输入视图和独占输出目录中工作。协调器将清单列出的文件物化为只读副本或受限挂载，验摘要后启动角色。工作进程不能读取 SQLite、公共对象区、其他尝试的 staging 或完整项目树。路径解析限制在角色视图内，拒绝绝对路径、目录跳转及指向视图外的链接；不得用可写硬链接暴露底层对象。模型上下文由协调器从同一清单构造。允许的运行库与编译工具单独登记。仅传一份 JSON、让同一用户进程继续拥有整盘读取权，不能验收为角色隔离。

## 预测提交与揭示

SQLite 在唯一协调器的短写事务中分配全库单调 commit_seq；一条有审计意义的事件对应一个序号，回滚的序号不参与历史，无需连续。Prediction 登记与 Reveal 必须分属不同的、有序提交。封装在工件外的不可变登记记录绑定 payload_sha、commit_seq、source_kind、context_snapshot 和可选的 supersedes；角色无权指定序号。这样无需将提交后的序号反写入已计算摘要的工件。

- 每组的可见快照包含组／继承分支、截至当时的最大 reveal_seq（初始为 0）、全部可见揭示记录及依赖版本的集合摘要。保留可重建的成员引用。Prediction 的输入清单绑定该快照；提交时比较组状态和水位，若制作预测期间发生本组新揭示，拒绝按旧上下文登记，重新分支或重算。在无当前组揭示的情况下，其他组的全局事件不会令其输入陈旧。
- 同一批次选例前锁定 prediction_batch 和 pool_digest。Reveal 记录 group、request_id、目标、契约、域、证据版本和 reveal_seq。物理结果生成时间、ready 时间以及其他组的 Reveal 均不替代本组揭示时间。任何标签交给角色前须先提交 Reveal；提交后即视为可知，即便进程在收到输入前崩溃。
- 审计时对齐**同组、同证据问题的首次已知揭示**，含继承分支、原裁决与后续勘误的版本链。预测晚于该次揭示，标为对该证据的事后判断；不得拿后来的更正时间抹去先前接触。若先看过其他案例的标签，再预测新目标，可以是该目标的轮内事前预测，同时标记为已受先前证据影响。
- 登记类别为 initial_registration、errata 或 post_remodel。只有锁定批次中的原登记可进入该批次的事前预测计数。errata 引用旧预测；post_remodel 引用父决定和可见快照；二者均可供后续回归。严格初始盲评还要求看见的标签仅限共同的种子前后基线；基线单独列在快照中。全局序号提供时间顺序，角色可见集合决定这次比较是否适用。

## 版本变化与恢复

| 变化或回退 | 保留 | 新版本及重新验收 |
| --- | --- | --- |
| B4 → A2，目标绑定、契约或骨架失真 | 旧输入与原始记录 | 重验受影响的映射、观测、裁决和依赖决定。新验证需求单独收费 |
| B4 → A5，全部解释被可信证据反驳 | 同组同版本的有效观测、裁决、已用预算与可见历史 | 重建解释与预测，标 post_remodel；重新校准和回归 |
| 预测误读或证据勘误 | 原预测、原揭示、每次决策时的快照 | 新记录带 supersedes 和原因。更正的裁决经新 Reveal 生效；旧证据的首次可见历史仍可重放 |
| 扩大观察域 | 原域内仍适用的单次见证 | 域版本、补证请求与覆盖依据更新；原小域反例不能直接推广 |
| C5 → C2／B4 | 纯实现偏差时保留规约及裁决；条款冲突时保留本组原证据 | 前者收费生成下一修复意图并回归，后者先交 B 开规约版本再编译。位置匹配勘误只重跑受影响映射与回归；若需要修改查询则按修复收费 |
